## 📌 About the Project

This project is an **Excel-based Sales Analytics Dashboard** created to analyze sales, profit, customers, products, regions, and monthly performance.

It combines **data analysis, PivotTables, PivotCharts, slicers, timeline filters, formulas, and data visualization** into one interactive dashboard.

---

## 🚀 Key Features

- 📈 Sales & Profit Analysis
- 👥 Customer Analysis
- 🏆 Top 10 Customers
- 🌍 Region-wise Sales Analysis
- 🛍️ Product Category Analysis
- 📅 Monthly Sales Trend
- 🔎 Interactive Slicers
- 🗓️ Interactive Order Date Timeline
- 📊 PivotTables & PivotCharts
- 📉 Linear Regression
- 📋 Descriptive Statistics
- 💡 What-If Analysis
- 📖 Data Storytelling

---

- Conditional Formatting
- Excel Formulas
- Data Analysis ToolPak
- Charts & Visualization

---

## 📊 Dashboard

The final dashboard provides an interactive overview of:

**Total Sales | Total Profit | Average Sales | Total Quantity**

Users can filter the dashboard by **Region, Product Category, and Order Date**.

---

## 🎯 Project Goal

To transform raw sales data into **meaningful insights and an interactive business dashboard** using Microsoft Excel.
